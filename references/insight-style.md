# Insight Style Reference

Use the SharePoint examples only to learn style, depth, and structure. Do not use them as live digest data.

## Desired Voice

- Write like an internal partner marketing operator briefing leadership.
- Lead with what changed and why it matters.
- Use plain business language: demand, throughput, backlog, concentration, urgency, data completeness, partner engagement, and operational risk.
- Be specific with numbers, but avoid burying the reader in raw rows.
- Prefer "story in brief" synthesis over metric listing.

## Patterns to Emulate

- Start with mission or strategic context when writing a leadership update.
- Convert metric clusters into insight: "Review-led demand dominates" is better than only listing sub-type counts.
- Flag concentration: top owners, top partners, or top sub-types that account for a large share of work.
- Separate fast typical handling from long-tail risk when both median/average and 90th percentile are available.
- Treat missing partner type, sub-type, account, or closed-date fields as analytical constraints.
- Call out partial-period caveats when the period ends mid-month or mid-quarter.
- End with practical takeaways that imply action, not generic observations.

## Example Insight Moves

- "Demand is heavily review-led" when Content Review/Creation plus PR/Blogs make up most volume.
- "Closure health looks strong, but the tail needs attention" when median close time is low and p90 is high.
- "Ownership is concentrated" when two or three owners handle more than half of cases.
- "Segment analysis is limited" when partner type or account fields have high missing rates.
- "Treat the period cautiously" when the latest month or quarter is incomplete.

## Output Adaptation

- If only high-level summary metrics are present, produce a narrative digest and a short caveat list.
- If tabular metrics are present, include a compact comparison table.
- If raw case examples are present, mine them for themes, not individual case retelling, unless the user asks.
- If the batch includes partner/account names, mention concentration and notable movement; avoid overexposing individual case descriptions unless operationally necessary.
- If prior-week metrics use different labels, compare only clearly equivalent fields and note label mismatch.

## Takeaway Quality Bar

Each "what matters most" takeaway should:

- Start with the operational implication.
- Include the metric or evidence that supports it.
- Say what to watch, investigate, or do next when appropriate.
- Include a Slack citation.

Poor: "There were 300 cases."

Better: "Demand is still scaling: the desk handled 300 requests, up 10% QoQ, which supports planning for continued intake growth."
